
# 🧭 NavGo

**Application Android de navigation GPS libre, rapide et gratuite.**

NavGo te guide à destination avec précision — calcul d'itinéraire, guidage vocal et suivi GPS en temps réel. Sans compte, sans publicité, sans limites.

---

## 📲 Téléchargement

👉 **[Télécharger NavGo v7 (APK)](https://github.com/allagattes55/navgo/raw/main/app-debug.apk)**

> Compatible Android 6.0 et supérieur

---

## ✨ Fonctionnalités

- 🗺️ **Calcul d'itinéraire** — Meilleur chemin calculé automatiquement via OpenStreetMap
- 📍 **Suivi GPS en temps réel** — Position précise mise à jour en continu
- 🔊 **Guidage vocal** — Instructions annoncées avant chaque manœuvre
- 🔄 **Recalcul automatique** — Si tu rates un tournant, l'itinéraire se recalcule instantanément
- ⭐ **Favoris** — Enregistre tes adresses fréquentes
- 🌙 **Thème sombre** — Interface adaptée à la conduite de nuit
- 🚨 **Signalement** — Signale des incidents sur la route

---

## 📱 Installation

1. Télécharge le fichier `app-debug.apk` ci-dessus
2. Sur ton Android, va dans **Paramètres → Sécurité** et active **Sources inconnues**
3. Ouvre le fichier APK et appuie sur **Installer**
4. NavGo est prêt ! 🎉

---

## 🛠️ Technologies

- **Android** (Kotlin)
- **Leaflet.js** — Carte interactive
- **OpenStreetMap** — Données cartographiques libres
- **OSRM** — Moteur de calcul d'itinéraire
